\# Sunny Senior Accessibility \& UI Skill



When generating components or modifying React files in this repository:

1\. Font sizes MUST use dynamic REM scaling (minimum base 18px/1.125rem).

2\. High-contrast colors are strictly enforced (WCAG AAA contrast ratios).

3\. Interactive elements require large tap targets (minimum 48x48px).

4\. Always pair visual alerts with Web Audio chimes or spoken TTS triggers.
